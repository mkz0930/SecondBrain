# 研究助手快速开始指南

## 前置条件

1. **Google API Key**: 需要有效的 Google Generative AI API Key
2. **本地内容**: 建议先在"外挂大脑"中添加一些内容，以便研究助手能够搜索到相关资料

## 配置步骤

### 1. 设置环境变量

在项目根目录创建 `.env` 文件（如果还没有）：

```bash
# Google Generative AI API Key
GOOGLE_API_KEY=your_api_key_here
# 或者使用
GEMINI_API_KEY=your_api_key_here

# 其他配置
PORT=3000
```

### 2. 启动服务

```bash
# 方式1: 使用启动脚本（推荐）
# Windows:
.\scripts\start.ps1
# Linux/Mac:
./scripts/start.sh

# 方式2: 手动启动（需要两个终端）
# 终端1 - 启动后端
npm run server

# 终端2 - 启动前端
npm run dev
```

### 3. 访问应用

打开浏览器访问: `http://localhost:5173`

## 使用示例

### 示例1: 研究 Vue 3 组件设计

1. **创建项目**
   - 点击"🔬 研究助手"
   - 点击"+ 新建研究项目"
   - 标题: "Vue 3 组件设计最佳实践"
   - 描述: "研究 Vue 3 中组件的设计模式、组合式API的使用、以及性能优化技巧"

2. **需求分析**
   - 点击"开始需求分析"
   - AI 会生成类似这样的问题：
     - "你想重点研究哪些方面？（基础概念、高级模式、性能优化）"
     - "你的目标是什么？（学习、项目应用、教学）"
     - "你目前对 Vue 3 的了解程度如何？"

3. **回答问题**
   - 逐个回答AI的问题
   - 例如: "我想重点研究组合式API和性能优化，目标是应用到实际项目中"

4. **收集资料**
   - 点击"开始收集资料"
   - 系统会从你的本地内容库中搜索相关文章、笔记

5. **分析资料**
   - 点击"开始分析资料"
   - AI 会分析资料之间的关联关系

6. **查看知识图谱**
   - 点击"🕸️ 知识图谱"
   - 可视化查看资料之间的关系

7. **生成报告**
   - 点击"📄 生成报告"
   - 获得结构化的研究报告

### 示例2: 研究技术选型

1. **创建项目**
   - 标题: "前端状态管理方案对比"
   - 描述: "对比 Pinia、Vuex、Zustand 等状态管理方案的优缺点"

2. **需求分析**
   - AI 可能会问：
     - "你的项目规模如何？"
     - "团队成员对哪些方案更熟悉？"
     - "有哪些特殊需求？（如SSR、TypeScript支持）"

3. **收集资料**
   - 从本地内容库搜索相关技术文章
   - 如果本地没有足够资料，可以先手动添加一些内容到"外挂大脑"

4. **生成报告**
   - 获得对比分析报告，包括各方案的优缺点、适用场景等

## 常见问题

### Q1: AI 分析失败怎么办？

**A**: 检查以下几点：
1. 确认 API Key 是否正确配置
2. 检查网络连接
3. 查看后端日志（`logs/combined-*.log`）
4. 如果是配额限制，等待一段时间后重试

### Q2: 搜索不到相关资料？

**A**:
1. 确保你的"外挂大脑"中已经添加了相关内容
2. 尝试使用更通用的研究主题
3. 手动添加一些相关内容后再试

### Q3: 知识图谱显示不正常？

**A**:
1. 确保已经完成"分析资料"步骤
2. 刷新页面重新加载
3. 检查浏览器控制台是否有错误

### Q4: 如何导出研究报告？

**A**:
目前可以通过以下方式：
1. 点击"复制报告"按钮，粘贴到其他应用
2. 使用浏览器的打印功能保存为PDF
3. 后续版本会添加直接导出功能

## 最佳实践

### 1. 准备充分的本地内容

在使用研究助手之前，建议先在"外挂大脑"中积累一些相关内容：
- 保存相关文章的URL
- 记录学习笔记
- 收藏技术文档

### 2. 明确研究目标

创建项时，尽量详细描述研究目标，这样AI能生成更有针对性的问题。

### 3. 认真回答问题

AI生成的问题是为了更好地理解你的需求，认真回答能获得更好的研究结果。

### 4. 迭代优化

如果第一次的结果不理想，可以：
- 创建新项目，调整研究主题
- 补充更多本地内容
- 调整问题的回答

### 5. 定期整理

完成研究后，可以将报告内容保存到"外挂大脑"中，作为新的知识积累。

## 技巧和窍门

### 1. 使用快捷键

- `Ctrl + Enter`: 在回答框中快速提交答案

### 2. 查看资料详情

- 点击资料卡片可以查看完整内容
- 相关度评分帮助你快速找到最相关的资料

### 3. 调整图谱布局

- 拖拽节点可以调整位置
- 使用缩放按钮调整视图
- 点击"重置视图"恢复初始布局

### 4. 分阶段进行

不必一次性完成所有步骤，可以：
- 今天创建项目和需求分析
- 明天收集资料
- 后天生成报告

项目会自动保存进度。

## 进阶用法

### 1. 多项目并行

可以同时创建多个研究项目，分别研究不同主题。

### 2. 状态筛选

使用左侧的状态筛选，快速找到特定阶段的项目。

### 3. 资料复用

同一份资料可能被多个项目使用，形成知识网络。

### 4. 报告再加工

生成的报告可以作为基础，进一步编辑和完善。

## 故障排除

### 后端启动失败

```bash
# 检查端口占用
netstat -ano | findstr :3000

# 如果端口被占用，可以修改 .env 文件中的 PORT
PORT=3001
```

### 前端编译错误

```bash
# 清除缓存重新安装
rm -rf node_modules
npm install
```

### 数据库错误

```bash
# 备份数据库
cp data/brain.db data/brain.db.backup

# 如果需要重置（会丢失数据）
rm data/brain.db
# 重启服务器会自动创建新数据库
```
