# 需求文档

本文档记录 Second Brain（外挂大脑）项目的整体需求。

## 项目概述

Second Brain 是一个智能个人知识管理工具，支持 Web 端和 Android 移动端，具备内容收集、AI 分析、飞书同步和研究助手功能。

---

## 功能需求

### 1. 内容管理

#### 1.1 内容类型
- 支持多种内容类型：随笔、文章、音视频、书籍
- AI 自动识别类型：公众号、抖音、文档、其他

#### 1.2 内容操作
- **创建**: 手动输入或粘贴 URL
- **读取**: 列表展示、详情查看、全文搜索
- **更新**: 编辑标题、内容、标签、评分
- **删除**: 软删除（保留 deleted_at）

#### 1.3 内容属性
| 属性 | 类型 | 说明 |
|------|------|------|
| title | string | 标题（AI 自动提取或手动输入） |
| content | text | 正文内容 |
| url | string | 来源 URL（可选） |
| source | string | 来源标识 |
| type | enum | 内容类型 |
| rating | int | 评分（1-5） |
| is_favorite | boolean | 是否收藏 |
| summary | text | AI 生成摘要 |
| tags | array | 标签列表 |

### 2. AI 内容分析

#### 2.1 分析功能
- 自动提取标题
- 生成 50 字以内摘要
- 识别内容类型
- 推荐相关标签
- 优化内容格式

#### 2.2 AI 模型
- 主模型：Google Gemini
- 降级链：gemini-3-flash-preview → gemini-2.5-flash-lite → gemini-2.5-flash → gemma-3-27b-it

### 3. 标签管理

#### 3.1 标签功能
- 创建自定义标签
- 为标签设置颜色
- 为内容添加多个标签
- 按标签筛选内容

### 4. 飞书同步

#### 4.1 同步功能
- 双向同步：本地 ↔ 飞书多维表格
- 自动同步：每 5 分钟检查一次
- 手动同步：用户触发立即同步
- 增量同步：只同步变更内容

#### 4.2 冲突解决
- 基于 updated_at 时间戳比较
- 较新版本覆盖较旧版本
- 时间相同时本地优先

#### 4.3 配置项
- app_id：飞书应用 ID
- app_secret：飞书应用密钥（加密存储）
- table_id：多维表格 ID

### 5. 每日总结

#### 5.1 总结功能
- AI 自动生成每日内容总结
- 支持查看历史总结
- 定时任务自动生成

### 6. 研究助手

#### 6.1 研究流程
1. 创建研究项目
2. AI 分析需求，生成研究问题
3. 从本地内容库搜索相关材料
4. AI 评估材料相关性
5. 生成知识图谱
6. 生成研究报告

#### 6.2 对话式交互
- 用户与 AI 对话完成研究
- 支持多轮对话
- 保存对话历史

### 7. 用户认证

#### 7.1 认证方式
- 用户名密码登录
- 微信小程序登录（openid）
- JWT Token 认证

#### 7.2 权限控制
- 用户只能访问自己的内容
- 支持匿名访问（可配置关闭）

### 8. Android 移动端

#### 8.1 剪切板监听
- 后台持续监听剪切板变化
- 智能识别文章 URL
- 自动过滤非文章内容（图片、视频、电商链接）

#### 8.2 离线队列
- 本地 SQLite 缓存
- 网络恢复后自动同步
- 指数退避重试机制

#### 8.3 通知交互
- 检测到链接后弹出通知
- 用户确认后保存
- 支持忽略操作

## 非功能需求

### 1. 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载 | < 3 秒 |
| API 响应 | < 500ms（不含 AI 分析） |
| AI 分析 | < 30 秒 |
| 同步延迟 | < 5 分钟 |

### 2. 可用性要求

- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 支持 Android 8.0+
- 响应式设计，支持移动端访问

### 3. 安全要求

- 密码加密存储
- 飞书密钥加密存储
- JWT Token 认证
- CORS 跨域保护

### 4. 可维护性要求

- 日志记录（Winston + 日志轮转）
- 错误追踪
- 数据库自动迁移

## 技术约束

### 1. 技术栈

**Web 前端**:
- Vue 3 + Composition API
- Pinia 状态管理
- Vue Router 路由
- Vite 构建工具
- Axios HTTP 客户端

**后端**:
- Node.js + Express.js
- SQLite 数据库
- Google Generative AI (Gemini)
- node-cron 定时任务

**Android 端**:
- React Native 0.73
- React Navigation 6
- SQLite 本地数据库
- react-native-background-actions

### 2. 环境要求

- Node.js >= 20.x
- npm >= 10.x
- Android SDK（Android 端）
- JDK 17（Android 端）

### 3. 外部依赖

- Google Gemini API（AI 功能）
- 飞书开放平台 API（同步功能）
- 微信开放平台（小程序登录）
