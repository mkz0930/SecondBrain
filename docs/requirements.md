# 需求文档

## 1. 首页列表排序优化
**日期**: 2026-01-17
**状态**: 进行中
**描述**: 
- 首页卡片列表需要按照“最新”的原则排序。
- “最新”定义为：最近更新（Created 或 Updated）的时间。
- 列表应按 `updated_at` 倒序排列。
- 列表分组（时间轴）应基于 `updated_at` 日期进行分组。

## 2. URL内容自动填充
**日期**: 2026-01-17
**状态**: 已完成
**描述**: 
- 当同步包含URL的记录时，自动抓取URL对应的网页内容。
- 仅当“内容正文”字段为空时，才将抓取的内容填充进去。
- 若“内容正文”已有内容，则保持原样，避免覆盖用户笔记。
