# 数据库看板功能文档

## 概述

数据库看板是一个用于查看和调试同步到本地数据库的数据的可视化工具。它提供了全面的数据库统计信息，帮助开发者和用户了解数据存储状态、同步情况和系统健康状况。

## 功能特性

### 1. 数据库概览
- **内容总数**: 显示所有未删除的内容数量
- **已删除内容**: 显示软删除的内容数量
- **标签数**: 显示所有标签的数量
- **标签关联**: 显示内容与标签的关联数量
- **注释数**: 显示内容注释的数量
- **访问记录**: 显示内容访问日志的数量
- **同步映射**: 显示飞书同步映射记录数量
- **同步日志**: 显示同步操作日志数量
- **每日总结**: 显示每日总结的数量
- **研究项目**: 显示研究项目的数量

### 2. 同步统计
- **同步状态**: 显示同步是否启用
- **最后同步时间**: 显示最近一次同步的时间
- **连续失败次数**: 显示连续同步失败的次数
- **总同步次数**: 显示所有同步操作的总数
- **成功率**: 显示同步成功的百分比
- **处理记录数**: 显示已处理的记录总数
- **冲突解决**: 显示已解决的冲突数量
- **同步方向分布**: 显示推送到飞书、从飞书拉取、双向合并的记录分布
- **最近同步记录**: 显示最近10次同步操作的详细信息

### 3. 内容统计
- **按类型分布**: 显示不同内容类型（随笔、文章、音视频、书籍等）的数量分布
- **按来源分布**: 显示不同来源（飞书、公众号、抖音等）的内容数量（Top 10）
- **收藏统计**: 显示收藏总数和平均评分
- **摘要覆盖率**: 显示有AI摘要的内容数量和覆盖率百分比
- **创建趋势**: 显示最近30天的内容创建时间线

### 4. 标签统计
- **最常用标签**: 显示使用次数最多的20个标签
- **未使用标签**: 显示从未被使用的标签列表
- **使用频率分布**: 显示标签使用次数的分布情况（0次、1-5次、6-10次、11-20次、20+次）

### 5. 研究统计
- **项目状态分布**: 显示不同状态的研究项目数量
- **问题统计**: 显示总问题数和已完成问题数
- **最近项目**: 显示最近更新的10个研究项目
- **材料类型**: 显示不同类型研究材料的数量分布

### 6. 每日总结统计
- **总结总数**: 显示所有每日总结的数量
- **平均长度**: 显示总结内容的平均字数
- **日期范围**: 显示最早和最新的总结日期
- **最近总结**: 显示最近30天的总结列表

## 使用场景

### 1. 调试同步问题
- 查看同步状态和最近的同步日志
- 检查同步失败的原因
- 查看同步方向分布，了解数据流向

### 2. 数据质量检查
- 查看内容摘要覆盖率
- 检查未使用的标签
- 查看删除的内容数量

### 3. 系统健康监控
- 查看同步成功率
- 检查连续失败次数
- 查看数据库表的记录数量

### 4. 内容分析
- 查看内容类型分布
- 查看内容来源分布
- 查看内容创建趋势

### 5. 研究项目管理
- 查看研究项目状态
- 查看研究问题完成情况
- 查看研究材料分布

## 技术实现

### 后端实现
- **路由文件**: `server/routes/database.js`
- **数据库查询**: 使用 SQLite 的聚合函数和 JOIN 查询
- **权限控制**: 使用 `requireUser` 中间件确保用户认证
- **日志记录**: 使用 Winston logger 记录错误

### 前端实现
- **视图组件**: `src/views/DatabaseView.vue`
- **路由配置**: `src/router/index.js`
- **数据获取**: 使用 Axios 并行请求所有统计数据
- **响应式设计**: 支持移动端和桌面端

### 性能优化
- **并行请求**: 使用 `Promise.all` 同时获取所有统计数据
- **索引优化**: 数据库查询使用已有的索引
- **数据缓存**: 前端缓存统计数据，支持手动刷新

## 注意事项

1. **权限要求**: 需要用户登录才能访问数据库看板
2. **数据隔离**: 每个用户只能看到自己的数据统计
3. **性能影响**: 统计查询可能对大数据量有一定性能影响，建议在非高峰期使用
4. **实时性**: 数据不是实时更新的，需要手动点击刷新按钮获取最新数据
