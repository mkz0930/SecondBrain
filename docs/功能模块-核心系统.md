# 功能模块 - 核心系统

## 1. 技术栈

### 前端
- **框架**: Vue 3
- **构建工具**: Vite
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **样式**: 原生 CSS

### 后端
- **运行环境**: Node.js
- **Web框架**: Express
- **数据库**: SQLite3 (本地存储)

## 2. 目录结构

```
second-brain/
├── data/           # 数据存储 (SQLite db文件)
├── server/         # 后端服务源码
│   ├── models/     # 数据库模型
│   ├── routes/     # API路由
│   ├── services/   # 业务逻辑服务

├── src/            # 前端源码
│   ├── views/      # 页面组件
│   ├── stores/     # Pinia状态库
│   ├── router/     # 路由配置
│   ├── components/ # 通用组件
│   └── utils/      # 工具函数
├── scripts/        # 启动脚本 (start.ps1, start.sh, start.py)
└── doc/            # 项目文档
```

## 3. 数据库设计

### 3.1 主要数据表
- **contents**: 内容主表，存储标题、正文、类型、评分等。
- **tags**: 标签表，存储标签名称和颜色。
- **content_tags**: 关联表，处理内容与标签的多对多关系。
- **annotations**: 批注表（预留）。
- **access_logs**: 访问日志表，记录内容的访问时间和次数。

## 4. 后端 API 接口

### 4.1 内容管理
- `GET /api/contents`: 获取内容列表（支持分页、筛选）。
- `GET /api/contents/:id`: 获取单个内容详情。
- `POST /api/contents`: 创建新内容。
- `PUT /api/contents/:id`: 更新内容。
- `DELETE /api/contents/:id`: 删除内容。
- `POST /api/contents/:id/favorite`: 切换收藏状态。
- `POST /api/contents/:id/access`: 记录访问日志。

### 4.2 标签管理
- `GET /api/tags`: 获取所有标签。
- `POST /api/tags`: 创建新标签。

### 4.3 统计信息
- `GET /api/stats`: 获取系统统计数据。

## 5. 快速启动

### Windows 系统
双击运行 `scripts/start.bat` 或在 PowerShell 中运行 `scripts/start.ps1`。

### Linux/Mac 系统
```bash
chmod +x scripts/start.sh
./scripts/start.sh
```

### Python 脚本 (跨平台推荐)
```bash
python scripts/start.py
```

### 手动开发模式
```bash
# 终端1 - 后端
npm run server

# 终端2 - 前端
npm run dev
```

## 6. 常见技术问题

### Q: 如何修改端口？
- **后端**：修改 `server/index.js` 中的 `PORT` 变量或通过环境变量 `PORT` 指定。
- **前端**：修改 `vite.config.js` 中的 `server.port`。

### Q: 数据库文件在哪里？
位于项目根目录的 `data/brain.db`。建议定期备份此文件。
