# 数据库看板使用指南

## 快速开始

### 访问数据库看板

1. **从首页访问**
   - 登录系统后，在首页顶部导航栏找到 **"📊 数据库"** 按钮
   - 点击按钮即可进入数据库看板

2. **直接访问**
   - 在浏览器地址栏输入：`http://localhost:5173/database`
   - 需要先登录才能访问

## 常见使用场景

### 场景1：调试同步失败

**问题**：飞书同步一直失败

**步骤**：
1. 打开数据库看板
2. 查看"同步统计"部分
3. 检查"连续失败次数"
4. 查看"最近同步记录"中的错误信息
5. 根据错误信息排查问题

**示例**：
```
连续失败: 3 次

最近同步记录:
定时同步 ✕
2026-01-18 15:00:00
错误: Token expired
```

**解决方案**：需要重新配置飞书 Token

### 场景2：检查数据质量

**问题**：想知道有多少内容有AI摘要

**步骤**：
1. 打开数据库看板
2. 查看"内容统计"部分
3. 查看"摘要覆盖率"

**示例**：
```
有摘要内容  120
摘要覆盖率  80.00%
```

**分析**：80%的内容有摘要，数据质量良好

### 场景3：清理未使用标签

**问题**：标签太多，想清理未使用的

**步骤**：
1. 打开数据库看板
2. 查看"标签统计"部分
3. 查看"未使用标签"列表
4. 记录需要删除的标签
5. 在标签管理页面删除

**示例**：
```
未使用标签 (5):
[测试]
[临时]
[待整理]
[草稿]
[备份]
```

### 场景4：分析内容来源

**问题**：想知道内容主要来自哪里

**步骤**：
1. 打开数据库看板
2. 查看"内容统计"部分
3. 查看"按来源分布"

**示例**：
```
飞书      60 条 (50%)
公众号    30 条 (25%)
抖音      20 条 (17%)
其他      10 条 (8%)
```

**分析**：主要内容来自飞书，其次是公众号

### 场景5：监控系统健康

**问题**：定期检查系统运行状况

**步骤**：
1. 打开数据库看板
2. 检查各项指标：
   - 同步成功率 > 95%
   - 连续失败次数 = 0
   - 摘要覆盖率 > 70%
   - 内容增长正常

**健康指标**：
```
✓ 同步成功率: 96.00%
✓ 连续失败: 0 次
✓ 摘要覆盖率: 80.00%
✓ 今日新增: 5 条
```

## 刷新数据

数据不是实时更新的，需要手动刷新：

1. 点击页面右上角的 **"🔄 刷新"** 按钮
2. 等待数据加载完成
3. 查看最新的统计信息

**建议刷新时机**：
- 完成同步操作后
- 批量添加内容后
- 修改标签后
- 定期检查时

## 性能提示

### 加载时间

- 正常情况：1-3 秒
- 数据量大时：3-5 秒
- 网络慢时：5-10 秒

### 优化建议

1. **避免频繁刷新**
   - 数据变化不大时无需频繁刷新
   - 建议间隔至少 1 分钟

2. **非高峰期使用**
   - 统计查询会占用一定资源
   - 建议在非高峰期查看

3. **关注关键指标**
   - 不需要每次都查看所有数据
   - 重点关注同步统计和内容统计

## 故障排查

### 问题1：页面加载失败

**症状**：显示"加载数据失败"

**可能原因**：
- 后端服务未启动
- 网络连接问题
- 数据库错误

**解决方案**：
1. 检查后端服务是否运行
2. 查看浏览器控制台错误
3. 查看后端日志文件

### 问题2：数据显示为0

**症状**：所有统计数据都是0

**可能原因**：
- 数据库为空
- 用户数据隔离问题
- 查询错误

**解决方案**：
1. 检查是否有内容数据
2. 确认登录的用户正确
3. 查看后端日志

### 问题3：同步统计不准确

**症状**：同步统计与实际不符

**可能原因**：
- 同步日志未正确记录
- 数据库数据不一致

**解决方案**：
1. 重新执行同步操作
2. 刷新数据库看板
3. 检查同步日志表

## 快捷键

目前暂不支持快捷键，所有操作通过鼠标点击完成。

## 移动端使用

数据库看板支持移动端访问：

- 响应式布局自动适配
- 卡片式设计便于滚动查看
- 所有功能完整支持

**移动端建议**：
- 横屏查看效果更好
- 重点查看概览和同步统计
- 详细数据建议在桌面端查看

## 数据隐私

- 所有数据仅当前用户可见
- 不同用户数据完全隔离
- 统计数据不会被分享或上传

## 技术支持

如遇到问题，请：

1. 查看浏览器控制台错误
2. 查看后端日志文件（`logs/` 目录）
3. 检查数据库文件（`data/brain.db`）
4. 提交 Issue 到 GitHub
