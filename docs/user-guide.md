## 快速上手

### 首次使用

1. **启动应用**

   按照主 README 中的说明启动应用，访问 http://localhost:5173

2. **登录系统**

   - 默认情况下，系统会自动创建一个匿名用户
   - 如需创建正式账号，点击"登录"按钮进行注册
   - 支持用户名密码登录

3. **开始记录**

   - 点击右上角"+ 新建内容"按钮
   - 选择内容类型，填写信息后保存

## 内容管理

### 内容类型

Second Brain 支持以下内容类型：

| 类型 | 说明 | 推荐用途 |
|------|------|----------|
| 随笔 | 日常想法、灵感和零散笔记 | 快速记录、备忘 |
| 文章 | 有结构的完整文章 | 学习笔记、读书笔记 |
| 音视频 | 音频、视频内容的记录 | 播客笔记、视频教程 |
| 书籍 | 书籍阅读记录 | 读书笔记、书单 |

### 创建内容

1. **进入编辑页**

   点击首页右上角的 **"+ 新建内容"** 按钮

2. **填写基本信息**

   - **类型**：选择内容类型（随笔/文章/音视频/书籍）
   - **标题**：可以手动填写，也可以让 AI 自动提取
   - **内容**：输入正文���容，支持 Markdown 格式

3. **可选信息**

   - **来源 URL**：如果是网络内容，可以填写来源链接
   - **评分**：点击星星进行 1-5 星评分
   - **标签**：选择已有标签或创建新标签

4. **保存**

   点击"保存"按钮完成创建

### 编辑内容

1. **进入编辑**

   - 在内容卡片上点击"编辑"按钮
   - 或在内容详情页点击"编辑"按钮

2. **修改内容**

   修改任意字段后保存

3. **使用 AI 分析**

   点击"AI 分析"按钮，让 AI 重新分析当前内容：
   - 提取更准确的标题
   - 生成摘要
   - 自动分类内容类型
   - 推荐相关标签
   - 优化内容格式

### 删除内容

- 在内容卡片上点击"删除"按钮
- 内容会进入软删除状态（可在后台恢复）
- 删除后不会在列表中显示

### 查看内容详情

点击任意内容卡片进入详情页：

- **Markdown 渲染**：富文本内容展示
- **元信息展示**：类型、来源、评分、标签、创建时间
- **访问统计**：显示访问次数
- **附件识别**：自动识别图片和文件链接

## AI 功能

### AI 内容分析

AI 可以帮助你自动分析和整理内容：

**功能说明：**

| 功能 | 说明 |
|------|------|
| 标题提取 | 从内容中自动提取合适的标题 |
| 摘要生成 | 生成内容摘要，方便快速回顾 |
| 类型识别 | 自动识别内容类型（公众号、抖音、文档等） |
| 标签推荐 | 根据内容推荐相关标签 |
| 格式优化 | 自动整理内容结构，添加 Markdown 格式 |

**使用方法：**

1. 在编辑页面填写内容
2. 点击"AI 分析"按钮
3. 等待分析完成（通常 3-10 秒）
4. 查看并确认 AI 的建议

**提示：** 即使手动填写了标题，AI 分析也可以帮助优化摘要和标签。

### 每日总结

每日总结功能会自动生成当天的内容汇总：

**查看每日总结：**

1. 在首页顶部找到"每日总结"区域
2. 选择日期查看对应日期的总结
3. 总结包含：
   - 当天创建的所有内容
   - 按类型分组
   - AI 生成的总结文字

**自动生成规则：**

- 系统会在每天 23:55 自动生成当日总结
- 如需手动生成，可在设置中触发

## 标签系统

### 创建标签

1. **在编辑内容时创建**

   - 在"标签"输入框输入新标签名称
   - 选择标签颜色
   - 按回车或点击"创建"完成

2. **通过标签页面创建**

   - 点击左侧边栏的"标签"选项
   - 点击"新建标签"按钮

### 使用标签

**筛选内容：**

- 在首页左侧筛选栏点击标签
- 支持多选标签筛选
- 点击标签名可查看该标签下的所有内容

**标签颜色：**

| 颜色 | 建议用途 |
|------|----------|
| 红色 | 重要、紧急 |
| 橙色 | 待办、进行中 |
| 黄色 | 需要跟进 |
| 绿色 | 已完成 |
| 蓝色 | 参考资料 |
| 紫色 | 个人思考 |
| 灰色 | 归档 |

### 管理标签

- 重命名标签
- 修改标签颜色
- 删除标签（不会删除关联内容）

## 飞书同步

### 配置飞书同步

1. **获取飞书凭证**

   - 在飞书开放平台创建应用
   - 获取 App ID 和 App Secret

2. **填写配置**

   - 点击设置中的"飞书同步"
   - 填入 App ID 和 App Secret
   - 选择要同步的飞书表格

3. **启动同步**

   - 点击"立即同步"进行首次同步
   - 系统会自动匹配字段

### 同步模式

**双向同步：**

- 本地修改会同步到飞书
- 飞书修改会同步到本地
- 基于时间戳处理冲突

**增量同步：**

- 只同步有变更的内容
- 减少网络传输和处理时间

**同步频率：**

- 自动同步：每 5 分钟
- 手动同步：点击"立即同步"按钮

### 同步状态

在首页顶部可以看到同步状态：

- **已同步**：显示最后同步时间
- **同步中**：显示进度条
- **同步失败**：显示错误信息

### 重置并拉取

如需重新初始化数据：

1. 点击"重置并拉取"
2. 确认操作
3. 系统会清空本地数据，从飞书全量拉取

## 智能评分

### 评分规则

系统会根据以下因素自动计算评分：

| 因素 | 权重 | 说明 |
|------|------|------|
| 内容长度 | 20% | 内容越充实，评分越高 |
| 访问次数 | 30% | 访问越多，评分越高 |
| 收藏状态 | 30% | 收藏的内容评分更高 |
| 标签数量 | 10% | 标签越多，说明越重要 |
| 年龄 | 10% | 新内容略有加分 |

### 查看评分

- 在内容卡片上显示星级评分
- 鼠标悬停可看到具体分数
- 按评分排序查看高质量内容

## 数据管理

### 备份数据

**自动备份：**

- 数据库文件位于 `data/brain.db`
- 建议定期复制此文件到安全位置

**手动备份：**

```bash
# Windows
copy data\brain.db backup\brain_%date%.db

# Linux/Mac
cp data/brain.db backup/brain_$(date +%Y%m%d).db
```

**定期备份建议：**

```bash
# 建议每周备份一次
cp data/brain.db data/backup/brain_$(date +%Y%m%d).db
```

### 数据清理

定期清理不需要的内容：
- 删除过时内容
- 合并重复内容

### 导出数据

支持导出为 Markdown 格式（即将推出）

## 技巧与建议

### 内容管理建议

#### 1. 建立标签体系

推荐建立清晰的标签分类体系：

```
一级分类：技术、生活、学习、工作
二级分类：前端、后端、算法、设计
状态标签：待读、已读、精华、归档
```

#### 2. 善用评分系统

- 5 星：顶级内容，定期回顾
- 4 星：优质内容，值得收藏
- 3 星：一般内容，快速浏览
- 1-2 星：参考内容，记录即可

#### 3. 定期整理

- 每周回顾新增内容
- 每月整理标签体系
- 定期删除过时内容

### 搜索技巧

- 使用核心关键词而非完整句子
- 尝试不同的关键词组合
- 使用专业术语提高精准度

## 常见问题

### Q: AI 分析失败怎么办？

**A:** 可能原因：
1. 未配置 GOOGLE_API_KEY
2. API Key 无效或配额不足
3. 网络连接问题

**解决方法：**
1. 检查环境变量配置
2. 验证 API Key 是否有效
3. 查看日志文件了解详细错误

### Q: 同步冲突怎么处理？

**A:** 系统会自动处理：
- 保留较新的版本（基于 updated_at）
- 如果时间相同，保留本地版本

### Q: 如何恢复删除的内容？

**A:** 删除的内容会保留在数据库中（软删除），如需恢复，请联系管理员或直接操作数据库。

### Q: 标签太多怎么管理？

**A:** 建议：
1. 定期合并相似标签
2. 删除不常用的标签
3. 使用标签颜色分类
