# 外挂大脑 Android 快速开始指南

## 5 分钟快速上手

### 步骤 1: 安装依赖

```bash
cd mobile
npm install
```

### 步骤 2: 启动后端服务器

在另一个终端：
```bash
cd ..
npm run server
```

### 步骤 3: 运行 Android 应用

**方式 1: 使用快速启动脚本**

Windows:
```powershell
.\start.ps1
```

Linux/Mac:
```bash
chmod +x start.sh
./start.sh
```

**方式 2: 手动启动**

终端 1 - 启动 Metro:
```bash
npm start
```

终端 2 - 运行应用:
```bash
npm run android
```

### 步骤 4: 首次配置

1. 打开应用后，点击右上角进入"设置"
2. 输入用户名和密码登录
3. 返回主页
4. 打开"剪切板监听"开关
5. 授予通知权限（如果系统提示）

### 步骤 5: 测试功能

1. 在浏览器打开一篇文章（如微信公众号）
2. 复制文章链接
3. 查看通知
4. 点击"保存"
5. 在主页查看同步统计
6. 点击"查看内容列表"确认保存成功

## 常见问题

### Q: 无法连接到服务器

**A:** 检查以下几点：
- 后端服务器是否运行（`npm run server`）
- 模拟器使用 `http://10.0.2.2:3000`
- 真机使用电脑的局域网 IP（如 `http://192.168.1.100:3000`）

### Q: 监听不工作

**A:** 确保：
- 监听开关已打开
- 通知权限已授予
- 应用在前台或后台运行（未被杀死）

### Q: 同步失败

**A:** 检查：
- 网络连接是否正常
- 是否已登录
- 后端服务器是否正常运行
