## 🚀 快速开始

### 安装和运行

```bash
# 1. 安装依赖
cd mobile
npm install

# 2. 启动后端（新终端）
cd ..
npm run server

# 3. 运行 Android 应用
cd mobile
npm run android
```

### 首次配置

1. 打开应用，进入"设置"
2. 登录账号
3. 开启"剪切板监听"
4. 授予通知权限

### 测试功能

1. 在浏览器复制文章链接
2. 查看通知
3. 点击"保存"
4. 确认同步成功
