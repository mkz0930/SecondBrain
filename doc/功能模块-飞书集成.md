# 功能模块 - 飞书集成

## 1. 功能概述
本模块实现了本地内容与飞书多维表格的双向同步，支持数据在两端自由流动，方便用户在移动端通过飞书进行知识管理。

### 主要特性
- ✅ **双向同步**：支持 Push（本地->飞书）和 Pull（飞书->本地）。
- ✅ **全内容覆盖**：支持随笔、文章、音视频、书籍所有类型。
- ✅ **自动同步**：支持定时自动同步（默认15分钟）。
- ✅ **冲突处理**：采用飞书端优先策略，自动解决数据冲突。
- ✅ **完整日志**：记录每次同步的详细信息。

## 2. 使用指南

### 2.1 前置准备
1. **创建飞书应用**：
   - 访问飞书开放平台，创建企业自建应用。
   - 开启机器人能力。
   - 获取 **App ID** 和 **App Secret**。
2. **配置权限**：
   - 添加 `bitable:app` (多维表格应用权限)。
   - 添加 `bitable:app:readonly` 和 `bitable:app:readwrite`。
3. **创建多维表格**：
   - 创建一个新的多维表格，获取 **Table ID** (url中的 `table=xxxx`)。

### 2.2 系统配置
**环境变量配置** (`.env`)：
```env
FEISHU_ENCRYPTION_KEY=your-32-char-random-key
FEISHU_SYNC_ENABLED=true
FEISHU_SYNC_DEFAULT_INTERVAL=15
```

**API配置**：
通过 `/api/feishu/config` 接口设置 App ID, App Secret 和 Table ID。

### 2.3 飞书表格字段映射
系统会自动在飞书表格创建以下字段：
| 字段名称 | 类型 | 说明 |
|---------|------|------|
| 记录ID | 单行文本 | 本地唯一标识 |
| 标题 | 单行文本 | |
| 内容类型 | 单选 | 随笔/文章/音视频/书籍 |
| 内容正文 | 多行文本 | |
| 来源 | 单行文本 | URL或出处 |
| 评分 | 数字 | 1-5 |
| 是否收藏 | 复选框 | |
| 标签 | 多选 | |
| 创建/更新时间 | 日期时间 | |

## 3. 技术实现详情

### 3.1 核心模块
- **FeishuAdapter** (`server/services/feishu-adapter.js`):
  - 负责飞书 OpenAPI 的调用。
  - 处理认证 (Tenant Access Token) 的自动获取和刷新。
  - 处理 API 限流和错误重试。
  - 实现本地数据与飞书记录（Record）的格式转换。

- **SyncService** (`server/services/sync-service.js`):
  - 核心同步逻辑引擎。
  - **Push 流程**: 扫描本地 `updated_at` > 上次同步时间的记录 -> 推送飞书。
  - **Pull 流程**: 扫描飞书端更新记录 -> 更新本地数据库。
  - **冲突解决**: 比较两端更新时间，若冲突则强制使用飞书端数据覆盖本地。
  - **日志记录**: 将同步结果写入 `feishu_sync_log` 表。

- **SyncScheduler** (`server/services/sync-scheduler.js`):
  - 基于 `node-cron` 实现定时任务。
  - 管理同步任务的生命周期（启动、停止、故障自动熔断）。

### 3.2 数据库设计
- **feishu_sync_config**: 存储飞书应用的 AppID, Secret (加密), TableID 等配置。
- **feishu_sync_mapping**: 记录本地 content_id 与飞书 record_id 的映射关系，以及上次同步的 hash 值用于变更检测。
- **feishu_sync_log**: 同步历史日志。

### 3.3 安全性
- **加密存储**: `App Secret` 使用 AES-256 加密存储在数据库中，密钥由环境变量 `FEISHU_ENCRYPTION_KEY` 提供。
- **隔离性**: 飞书配置基于用户（当前单用户设计，预留多用户字段）。

## 4. API 接口说明

### 配置管理
- `GET /api/feishu/config`: 获取当前配置状态。
- `POST /api/feishu/config`: 保存配置。
- `POST /api/feishu/config/test`: 测试连接。

### 同步操作
- `POST /api/feishu/sync`: 手动触发同步 (参数: `{ direction: "both" }`)。
- `GET /api/feishu/sync/history`: 获取同步历史日志。
- `POST /api/feishu/import-all`: 全量将本地数据导入飞书（初始化用）。

## 5. 常见问题与维护
- **同步失败**: 检查日志中的错误信息。常见原因为 Token 过期（会自动刷新）或网络波动。
- **冲突**: 系统自动以飞书数据为准。
- **数据备份**: 建议定期备份 `data/brain.db`，飞书端数据可作为云端备份，但不建议作为唯一备份。
