# 需求文档

## 1. 项目概述
**外挂大脑（Second Brain）** 是一个个人知识管理工具，旨在帮助用户积累和组织日常见闻、随笔、文章、音视频和书籍等多类型内容。系统支持本地部署，并通过飞书多维表格实现移动端数据的双向同步。

## 2. 核心功能需求

### 2.1 内容管理
- **多类型支持**：支持随笔、文章、音视频、书籍四种基本内容类型。
- **CRUD操作**：支持内容的创建、读取、更新和删除。
- **属性管理**：
  - 标题、正文、摘要、URL链接、来源。
  - 评分系统（1-5星）。
  - 收藏状态标记。
  - 自动记录创建时间和更新时间。

### 2.5 AI内容分析
- **智能提取**：引入免费大模型（如Gemini），自动分析输入内容。
- **字段提取**：
  - 自动提取标题至标题字段。
  - 若内容包含URL，自动提取至URL字段。
- **URL解析**：自动读取提取到的URL内容。
- **智能摘要**：根据内容（或URL内容）生成摘要。
- **智能分类**：自动更新分类结果为：随便、抖音、公众号、文档、或其他。

### 2.2 标签系统
- **自定义标签**：支持创建和管理自定义标签。
- **标签关联**：一个内容可关联多个标签。
- **颜色标记**：支持为标签设置不同颜色。
- **标签统计**：统计每个标签下的内容数量。

### 2.3 搜索与筛选
- **全文搜索**：支持对标题、正文、来源进行关键词搜索。
- **多维筛选**：
  - 按内容类型筛选。
  - 按收藏状态筛选。
  - 按标签筛选。

### 2.4 数据统计
- **概览统计**：展示内容总数、标签总数、收藏总数。
- **分布统计**：展示各类型内容的分布情况。
- **访问统计**：记录并展示最近访问和最常访问的内容。

## 3. 飞书集成需求

### 3.1 双向同步
- **本地到飞书 (Push)**：检测本地新增、修改、删除的内容，自动推送到飞书多维表格。
- **飞书到本地 (Pull)**：获取飞书表格的新增和修改记录，同步回本地数据库。
- **全字段覆盖**：同步标题、类型、正文、来源、评分、收藏状态、标签、时间等所有核心字段。

### 3.2 冲突处理
- **冲突检测**：识别同一记录在两端同时被修改的情况。
- **解决策略**：采用**飞书端优先**策略，当冲突发生时，飞书的数据覆盖本地数据。

### 3.3 自动同步
- **定时任务**：支持配置定时自动同步（默认15分钟）。
- **开关控制**：支持启用/禁用自动同步功能。

### 3.4 可靠性与安全
- **错误重试**：API调用失败自动重试。
- **限流处理**：智能处理飞书API限流。
- **字段自适应**：自动适配飞书表格字段，防止字段不匹配导致同步失败。
- **敏感信息加密**：对App Secret等敏感配置进行加密存储。
- **同步日志**：完整记录每次同步的详细信息（成功、失败、冲突数等），便于排查。

## 4. 非功能性需求
- **UI风格**：未来科技风，简约大气，偏暗色（参考 Google AI Studio）。
- **数据隐私**：核心数据存储在本地 SQLite 数据库。
- **部署方式**：支持 Windows/Linux/Mac 多平台部署。
- **启动便捷**：提供一键启动脚本。
