## 下一步操作指南

### 1. 配置环境变量
```bash
# 复制示例配置
cp .env.example .env

# 编辑 .env 文件，设置：
# - FEISHU_ENCRYPTION_KEY（必须修改为安全的随机字符串）
# - FEISHU_SYNC_ENABLED（是否启用自动同步）
# - FEISHU_SYNC_DEFAULT_INTERVAL（默认同步间隔）
```

### 2. 创建飞书应用
1. 访问 https://open.feishu.cn/
2. 创建企业自建应用
3. 配置所需权限（bitable相关）
4. 获取 App ID 和 App Secret

### 3. 创建飞书表格
1. 在飞书中创建多维表格
2. 获取表格ID（格式：appToken_tableId）
3. 记录表格信息备用

### 4. 配置系统
通过API接口配置飞书集成：
```bash
POST /api/feishu/config
{
  "app_id": "cli_xxxx",
  "app_secret": "xxxx",
  "table_id": "bascxxxx_tblxxxx",
  "sync_interval": 15
}
```

### 5. 首次同步
执行全量导入，将现有内容同步到飞书：
```bash
POST /api/feishu/import-all
```

## 性能指标

### 批量操作限制
- 单次批量操作：最多500条记录
- 请求间隔：200ms
- 重试次数：最多3次
- Token有效期：2小时（自动刷新）

### 推荐配置
- 内容量 < 1000条：同步间隔 5-10分钟
- 内容量 1000-5000条：同步间隔 15-30分钟
- 内容量 > 5000条：同步间隔 30-60分钟
