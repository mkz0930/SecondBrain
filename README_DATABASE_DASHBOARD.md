## 📋 功能概述

数据库看板是一个用于查看和调试同步到本地数据库的数据的可视化工具，提供了全面的数据统计和分析功能。

### 核心功能

✅ **6个统计模块**，覆盖**70+项**数据指标：

1. **📦 数据库概览** - 所有表的记录数量统计
2. **🔄 同步统计** - 飞书同步状态、成功率、历史记录
3. **📝 内容统计** - 类型、来源、评分、趋势分析
4. **🏷️ 标签统计** - 使用频率、未使用标签分析
5. **🔬 研究统计** - 项目状态、问题完成情况
6. **📅 每日总结统计** - 总结数量、质量分析

## 🚀 如何使用

### 方式1：从首页访问
1. 登录系统
2. 点击顶部导航栏的 **"📊 数据库"** 按钮

### 方式2：直接访问
```
http://localhost:5173/database
```

### 主要操作
- **查看数据**：页面自动加载所有统计信息
- **刷新数据**：点击右上角 "🔄 刷新" 按钮
- **返回首页**：点击右上角 "← 返回" 按钮

---

## 💡 典型使用场景

### 1. 调试同步问题 🔍
当飞书同步失败时：
- 查看"同步统计"模块
- 检查"连续失败次数"
- 查看"最近同步记录"中的错误信息
- 根据错误信息排查问题

### 2. 检查数据质量 ✅
想了解数据情况时：
- 查看"内容统计"模块
- 查看"摘要覆盖率"（AI摘要生成情况）
- 查看"按类型分布"（内容类型分布）
- 查看"创建趋势"（最近30天趋势）

### 3. 清理未使用标签 🏷️
标签管理时：
- 查看"标签统计"模块
- 查看"未使用标签"列表
- 识别需要清理的标签
- 在标签管理页面删除
