# UI 风格优化计划：未来科技风 (Dark Mode)

## 1. 核心设计语言
- **配色方案**：
  - **背景**：深邃黑/深蓝 (`#0b0e14`, `#13161c`)，搭配微弱的渐变光晕。
  - **卡片**：半透明深灰 (`rgba(30, 41, 59, 0.7)`) + 背景模糊 (Backdrop Blur)，营造玻璃质感。
  - **文字**：高对比度白/灰 (`#e2e8f0`, `#94a3b8`)。
  - **强调色**：霓虹蓝 (`#3b82f6`) 和 霓虹紫 (`#8b5cf6`)，用于按钮、高亮和光效。
- **视觉元素**：
  - 圆角设计 (Rounded Corners)。
  - 微发光效果 (Glow Effects)。
  - 极简边框 (Subtle Borders)。

## 2. 实施步骤

### 2.1 全局样式重构 (`src/assets/main.css`)
- 定义 `:root` CSS 变量，统一管理颜色系统。
- 重置基础 HTML 元素样式（body, input, button）为深色模式。
- 定义通用的 `.card`, `.btn` 样式，减少重复代码。

### 2.2 页面样式适配
- **首页 (HomeView)**：
  - 替换背景为深色动态渐变。
  - 内容卡片增加悬停发光效果。
  - 侧边栏过滤器适配深色背景。
- **详情页 (ContentDetailView)**：
  - 优化阅读体验，确保文字在深色背景下清晰易读。
  - 信息面板使用半透明设计。
- **编辑页 (ContentEditView)**：
  - 输入框和编辑器适配深色模式，去除默认的白色背景。
- **登录页 (LoginView)**：
  - 更新背景和登录卡片样式，使其更具科技感。

## 3. 预期效果
- 界面将转变为以深色为主的沉浸式体验。
- 视觉风格接近 Google AI Studio，简约且富有科技感。
